# Flutter FAQ App

Aplicacion Flutter sencilla que muestra una lista de preguntas frecuentes con respuestas desplegables.

## Requisitos

- Flutter SDK 3.9.2 o superior compatible
- Dart SDK incluido con Flutter
- Android Studio, VS Code o un emulador/dispositivo configurado

## Instalacion

```bash
flutter pub get
```

## Ejecutar

```bash
flutter run
```

## Pruebas y analisis

```bash
flutter analyze
flutter test
```

## Estructura principal

- `lib/main.dart`: interfaz principal de la app FAQ.
- `test/widget_test.dart`: prueba de widget para validar la lista y la expansion de respuestas.
